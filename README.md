# Ravenswatch Mods

A collection of mods for **Ravenswatch**, built with
[Ravenswatch Mod Manager (RSMM)](https://github.com/Ovilli/RavenswatchModManager).
Some are finished gameplay mods, some are experiments, and some are tools used
while developing RSMM itself; each mod's `manifest.toml` describes it.

> Unofficial and fan-made. Not affiliated with or endorsed by Passtech Games or
> Nacon. Back up your saves before trying experimental mods.

## Requirements

- Ravenswatch on Steam (Windows, or Linux via Proton).
- **RSMM**: the [desktop app](https://github.com/Ovilli/RavenswatchModManager/releases/latest)
  or the `rsmm` command-line tool.
- The **RSMM loader**, for any mod that has an `init.lua`. The desktop app
  installs it for you; from the command line it is `rsmm install-loader`.
  Mods without an `init.lua` only replace game files and work without it.

## Installing a mod

1. Copy the mod's folder (for example `bloodlust/`) into RSMM's `mods/` folder.
2. Enable it, either in the desktop app or by setting `enabled = true` in its
   `manifest.toml`.
3. Apply:
   - **Desktop app:** press Play. It applies your mods before launching.
   - **Command line:**
     ```sh
     rsmm restore --all
     rsmm apply
     rsmm install-loader
     ```
4. Launch the game.

To remove every mod and put the game back the way it was, run
`rsmm restore --all`. Mods with settings have a `config_schema.toml`, which the
desktop app shows as a settings panel.

The folder `_merged/` is generated by `rsmm apply`. Don't copy or edit it.

## Multiplayer

Every manifest declares a `multiplayer_scope`:

| Scope | What it means in co-op |
|---|---|
| `local-only` | Only affects you. Other players don't need it. |
| `cosmetic` | Changes what you see, not how the game plays. Only you see it. |
| `deterministic-shared` | Changes the game itself, like the map, items or enemies. **Every player must run the same mod with the same settings**, or the game will desync. |

Mods marked **experimental** may break, and should be tried solo first.

## Making your own

Mods are data plus, optionally, Lua scripts that use the RSMM SDK. Good places
to start:

- [Modding guide](https://docs.rsmm.me/guides/modding/)
- [SDK reference](https://docs.rsmm.me/guides/sdk/)
- [`bloodlust`](bloodlust/) and [`second-wind`](second-wind/): short,
  self-contained Lua mods with no game files.

Two rules keep mods working across game updates: mods ship **data, not code**
(no Python beyond `on_disable.py`), and Lua uses only the high-level `R.*` API,
never raw memory addresses. `rsmm lint` checks both.

## Issues

Bugs in a mod: open an issue in this repository and include the output of
`rsmm log --errors` (it redacts nothing, so check it before posting).
Bugs in RSMM itself belong in the
[RSMM repository](https://github.com/Ovilli/RavenswatchModManager/issues).
