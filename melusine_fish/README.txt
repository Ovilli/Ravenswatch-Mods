Melusine: Blue Big Fish MOD 安装说明

1. 先安装 Ravenswatch 和 RSMM，并确保 RSMM 能识别游戏目录。
2. 把 melusine_fish.zip 发给要安装的人。
3. 安装方式二选一：
   - 推荐：打开 RSMM，选择“导入 / Install from archive”，选中 melusine_fish.zip。
   - 手动：解压后把 melusine_fish 文件夹放到 RSMM 的 mods 目录。
4. 在 RSMM 的 MOD 列表中启用 Melusine: Blue Big Fish。
5. 点击 Apply / 应用到游戏。
6. 启动 Ravenswatch，选择美露莘查看皮肤。

注意事项
- 这是角色模型覆盖 MOD，建议只在单机或双方都安装同款 MOD 的联机环境使用。
- 如果游戏或 RSMM 版本不同，贴图/几何 cooked 文件可能不兼容。
- 若安装后显示异常，先在 RSMM 里 Restore / 回退原版，再重新 Apply。
- 本 MOD 基于第三方 VRM 模型二次修改，公开发布前请确认模型作者授权。
